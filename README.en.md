# Fusion Reader for Zotero

A lightweight plugin for Zotero 7 and later that makes it easier to access document translation features through Fusion Reader.

## Usage

1. Install the latest version of Fusion Reader.
2. Install Zotero.
3. On the right side of this page, click **Releases → Version → Assets**, then download the `.xpi` file.
4. In Zotero, open **Tools → Plugins**, click the gear icon, and select **Install Plugin From File…**.
5. Select `fusion-reader-for-zotero.xpi`.
6. In the library view, select an item or PDF attachment, then click the **Fusion Reader** button in the toolbar. You can also access it from the right-click context menu.

## Build

We recommend downloading the pre-built package from **Releases**.

If you need to build the plugin yourself, run the following command in this directory:

```bash
./build.sh 
```
